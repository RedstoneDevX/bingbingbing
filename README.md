# 冰冰冰（bingbingbing）

一个单文件的冰块点击小游戏：HTML、CSS、JS 全部写在同一个 `index.html` 里，无依赖、无构建、离线可玩。

## 玩法

点击中央大冰块或周围的小冰块 → 计数 +1，并播放合成的“冰冰冰”清脆三连音；1.5 秒内连续点击会累积连击，连击越快等级涨得越快。

## 功能

| 模块 | 说明 |
|---|---|
| 计数与连击 | 总点击、当前连击、最高连击、等级进度；连击窗口 1.5 秒 |
| 音效 | **不用外部音频文件**，用 Web Audio API 合成：正弦载波 + 三角波泛音 + 快速衰减包络，三连音音高递减上扬 |
| 视觉效果 | 冰块点击抖动、冰屑粒子飞溅、`+1` 飘字、连击横幅、背景飘雪、三种冰系主题（极光蓝 / 极地白 / 深夜蓝）|
| 统计面板 | 总点击、连击、本次会话、最近一次时间、平均间隔 |
| 历史记录 | 带时间与连击数，可设上限 10 / 20 / 50 条，可单独清空 |
| 成就 | 11 个徽章（点击数 / 连击数 / 等级 / 会话数） |
| 存档 | 自动写入 localStorage；可导出为 JSON 文件，也可选文件或粘贴文本导入 |
| 快捷操作 | 空格键等同于点击主冰块 |

## 怎么玩

```
直接用浏览器打开 index.html
```

## 实现上的几个点

- **音效是算出来的**：不依赖任何音频资源，全部用 Web Audio 振荡器实时合成，所以单文件离线也能发声
- **状态合并而非覆盖**：读存档时以默认状态为骨架做两层合并，老存档缺字段不会报错
- **导入有校验**：检查 `total` 是否为有效非负数，数字字段统一取整兜底，避免脏数据把界面搞崩
- **历史渲染做了转义**：`escapeHtml` 处理 `& < > " '`，防止存档里的字符串变成 HTML

## 已知限制

- 连击窗口固定 1.5 秒，不可调
- 音效依赖浏览器 Web Audio，部分浏览器需先点击一次页面才能出声
- 没有排行榜与联机功能
